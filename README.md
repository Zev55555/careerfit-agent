# CareerFit Agent

**面向真实岗位 JD 的 AI 求职材料匹配原型。**

在线体验：[https://ai-zev-ai-resume-agent-saas.vercel.app/](https://ai-zev-ai-resume-agent-saas.vercel.app/)

## 项目简介

CareerFit Agent 不是简单的“AI 简历优化器”，而是一个围绕求职材料匹配场景设计的 AI 产品原型。

它从用户的 Master 简历出发，结合真实岗位 JD，分析岗位要求、匹配个人经历证据，并生成更贴近岗位筛选逻辑的定制简历。

项目重点解决三个问题：

- JD 关键词容易被硬贴，项目经历却没有真正支撑岗位职责；
- AI 容易过度包装，写出没有证据支撑的能力或结果；
- 定制过程中可能删掉原始简历里更有说服力的强证据。

## 核心能力

- **Master 简历导入**：支持 PDF 简历解析和 Master JSON 导入 / 导出。
- **JD 深度分析**：拆解岗位职责、任职要求、关键词、风险点和岗位方向。
- **经历证据匹配**：不只改技能区，也会让项目经历回应岗位职责。
- **N+1 项目桥接 bullet**：保留项目原始强证据，同时增加一条安全的岗位定向表达。
- **质量检查机制**：检测 JD 硬贴、AI 痕迹、过度包装、无证据关键词和项目证据削弱。
- **ATS 关键词覆盖**：检查 JD 核心关键词是否自然覆盖，避免关键词堆砌。
- **Master vs Generated 对比**：判断生成版本是否真的比原始 Master 更适合当前 JD。
- **A4 PDF 导出**：支持固定中文 A4 简历预览和 PDF 导出。

## 产品流程

```text
导入 Master 简历 → 粘贴岗位 JD → 分析岗位要求 → 生成定制简历 → 质量检查 → 导出 PDF
```

## 项目亮点

**不是通用改写，而是 JD 到经历证据的匹配。**  
系统会先判断岗位需要什么，再尽量从 Master 简历中找到可支撑的项目、技能和证据。

**不是关键词堆砌，而是有证据的 ATS-friendly。**  
缺少证据的关键词不会被硬塞进简历正文，而是作为风险提示。

**不是盲目生成，而是带质量防护。**  
系统会检测“对应 JD”“满足岗位要求”等 AI 痕迹，以及商业化上线、模型训练、企业级落地等高风险表达。

**不是越改越花，而是保护原始强证据。**  
如果定制版本削弱了 Master 简历中原本更有说服力的项目证据，系统会尝试修复。

## 效果验证

项目基于真实岗位 JD 做了原始版与生成版对照测试，并使用统一 HR 风格评分维度评估岗位匹配度。

在 50 条评分记录中，生成版平均分从 **74.52** 提升至 **81.26**，平均提升 **6.74 分**，胜率 **72%**。

该结果是产品 benchmark，不代表真实投递通过率、面试转化率或录用结果。

## 当前状态

CareerFit Agent 目前是一个 MVP / Prototype。

核心链路已经完成，并会继续基于真实 JD 测试迭代项目证据保护、N+1 项目桥接、质量检查和反过度包装机制。
