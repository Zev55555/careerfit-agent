# 中文 A4 简历模板风格指南

## 整体风格

- 中文 A4 单页 PDF 风格。
- 黑白配色，不使用花哨颜色、图标、头像、二维码或装饰边框。
- 页面干净、正式、紧凑，适合 AI 产品、数据分析、互联网实习投递。
- 视觉重点放在姓名、板块标题、项目标题和 bullet 小标题上。
- 不做成海报、作品集页面或卡片式网页。

## 页面布局

- A4 竖版，单页。
- 页面边距控制在 12-16mm。
- 内容尽量刚好填满一页，避免底部大面积留白，也避免挤到难以阅读。
- 一级板块之间要有清晰间距，但不能太松。
- 导出 PDF 后必须和页面预览尽量一致。

## 字体层级

- 姓名最大，顶部居中，字体加粗。
- 联系方式放在姓名下方，字号小于正文，单行展示。
- 一级板块标题加粗，并使用横线分隔。
- 项目标题加粗，字号略小于一级板块标题。
- 技术栈、GitHub、Website 链接字号保持一致。
- 正文字号统一，手机预览也要能看清。

## 内容排版

- 教育背景、专业技能、项目经历等板块清晰分隔。
- 项目经历使用圆点 bullet。
- 每条 bullet 尽量保持“小标题：具体内容”的格式。
- bullet 的小标题需要加粗，例如“场景抽象：”“数据分析链路：”“多场景验证：”。
- bullet 之间保持适度行距，不能糊在一起，也不能太空。
- 中英文之间保留自然空格，例如 SQL、Python、Pandas、AI Agent、Metric Spec。
- 所有项目链接风格统一。

## 压缩规则

- 优先压缩行距、段距、技能栏行和普通描述。
- 不压缩到正文难读。
- 不把 bullet 全部挤成一大段。
- 不让项目标题和 bullet 黏在一起。
- 最终效果应像正式投递简历，而不是网页截图或文档草稿。
